# Privacy

Ascension v2 has no accounts, analytics, remote AI calls or user prompt collection. Completed levels and best move counts are saved to this browser's localStorage under ascension.v2.progress. Clearing site data removes that progress. Storage failures do not prevent play.

Music, graphics and application assets are served by the same host. A hosting provider may retain ordinary server access logs under its own policy. Optional outbound GitHub and portfolio links navigate to third-party sites only when selected.
